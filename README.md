## ✨ Features

- **Dynamic Pixel Assembly** — thousands of scattered particles converge into a portrait on load
- **Interactive Mouse Repulsion** — hover disperses particles with fluid physics
- **Click Shockwave** — radial blast wave scatter on click
- **3D Interactive Solar System** — tech stack displayed as orbiting planets
- **Cyber-Mosaic Color Grading** — iridescent cyber silver, cyan & icy blue on pure black
- **Metallic Chrome Typography** — custom Google Fonts (`Syne` and `Plus Jakarta Sans`)
- **Fully Responsive** — seamless on all devices

---

## 🛠 Tech Stack

- HTML5 & CSS3
- Vanilla JavaScript (Canvas 2D API)
- GSAP & ScrollTrigger (animations)
- Three.js (3D solar system)

Open `http://localhost:5173/` in your browser.
