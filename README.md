# Interactive Cyber-Mosaic Particle Portfolio

An interactive portfolio hero page featuring a futuristic canvas pixel-dispersion effect, inspired by Hasibul Hasan's design.

## Features
- **Dynamic Pixel Assembly**: On page load, thousands of scattered particles converge to assemble into the portrait.
- **Interactive Mouse Repulsion**: Hovering over the portrait disperses the particles with fluid physics, snapping back when the cursor leaves.
- **Click Shockwave**: Radial blast wave scatter on click.
- **Cyber-Mosaic Color Grading**: Iridescent cyber silver, cyan, and icy blue square pixel matrix on pure black (`#000000`).
- **Metallic Chrome Typography**: Heavy metallic gradient text with custom Google Fonts (`Syne` and `Plus Jakarta Sans`).
- **Responsive Layout**: Designed for seamless scaling on all devices.

## Tech Stack
- HTML5 & CSS3
- Canvas 2D API (Vanilla JavaScript)

## Running Locally
Simply open `index.html` in any modern web browser or serve via a local server:
```bash
python -m http.server 5173
```
Open `http://localhost:5173/` in your browser.
